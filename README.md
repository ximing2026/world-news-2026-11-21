# One Picture, One Day: The World News of Saturday 21 November 2026

Everything that mattered on Saturday 21 November 2026, compressed into a single image laid out like the front page of a newspaper. The top story is the pair of tankers struck by projectiles nobody has claimed, in the sea off Oman near the mouth of the Strait of Hormuz. Around it sit 32 stories in total: six illustrated cards — a missile strike on Kryvyi Rih in Ukraine; a powerful earthquake in Peru; a researcher announcing, with an AI assistant's help, an as-yet unverified breakthrough on the Riemann hypothesis; the COP31 climate summit stuck in deadlock over fossil fuels; Denmark breaking up an alleged Russian assassination plot; and the Nasdaq giving back all of its 2026 gains — plus columns of shorter regional briefs, a strip of the day reduced to numbers, and a news ticker running along the bottom.

## Run it

```bash
python3 main.py
```

Running the script writes the poster to `/output/entry.png`. Before copying, it confirms the bundled artwork starts with the PNG magic bytes and stays within 1 MiB. It relies only on the Python 3 standard library, so there is nothing to install.
